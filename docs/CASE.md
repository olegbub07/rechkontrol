# Соответствие технологическому кейсу

Заказчик: ПАО КБ «Центр-инвест». Кейс: локальная платформа расшифровки звонков и оценки качества операторов для предпринимателя.

| Требование кейса | Где выполнено |
|---|---|
| Speech-to-Text локально (Whisper) | `faster-whisper`, модель в `data/models/`. Аудио в запрос к сети не входит |
| Структурированный текст | реплики с ролью, началом и концом в карточке звонка и в JSON |
| Вежливость, полнота, скрипт, решение и рекомендации | `app/quality.py`, карточка звонка |
| Записи и расшифровки не покидают сеть | `127.0.0.1`, офлайн-модель, оценка без облачных моделей |
| Запуск на ноутбуке или локальном сервере | `python run.py` или `.\run.ps1` |
| WAV, MP3, OGG | проверка сигнатуры в `app/audio.py`, загрузка в кабинете |
| Веб: загрузка, расшифровка, оценка, дашборд, экспорт | кабинет на `/` |
| KPI в CSV и JSON: нарушения, время ответа, тональность, дата и время, ID оператора | `app/api/export.py` |
| До 10 минут аудио за 3-5 минут | для записи от 3 минут: пакетный проход, луч 1, без пословной разметки. См. [PERFORMANCE.md](PERFORMANCE.md) |
| Очередь: часть обрабатывается, остальные ждут | статусы `queued` и `processing`, слоты `MAX_PARALLEL_JOBS` |

Итог кейса - прототип, в котором предприниматель получает расшифровку и оценку и видит метрики и тренд на дашборде. Этот блок продублирован на экране «Обзор».
