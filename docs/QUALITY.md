# Оценка качества диалога

Движок `app/quality.py` работает только по тексту и таймкодам. Облачные LLM не используются: записи не должны покидать контур.

## Четыре метрики (0–100)

Итог:

`0.28 × вежливость + 0.22 × полнота + 0.25 × скрипт + 0.25 × решение`

Грубая формулировка в речи оператора дополнительно снижает итог.

### Вежливость

- приветствие;
- обращение на «вы»;
- формулы вежливости;
- эмпатия, если клиент встревожен;
- отсутствие грубости и перебиваний.

### Полнота

- ответы на вопросы клиента;
- содержательность реплик оператора;
- пауза перед ответом (ориентир до 3 секунд).

### Скрипт

- представление;
- название компании (список настраивается);
- предложение помощи;
- уточнение запроса;
- корректное завершение;
- дополнительные обязательные фразы из настроек.

### Решение проблемы

- озвучено действие или результат;
- назван следующий шаг, срок или номер обращения;
- есть подтверждение, что вопрос закрыт;
- диалог не брошен и клиент не отправлен «не туда».

## Процент нарушений

Доля пунктов чек-листа, которые не пройдены. Именно это поле уходит в CSV/JSON как «процент нарушений».

## Тональность

Лексическая оценка речи оператора и клиента: `positive` / `neutral` / `negative`. Грубость фиксирует негатив.

## Рекомендации

Формируются только по проваленным проверкам, с конкретным советом («представьтесь по имени», «назовите номер обращения»). Если итог ≥ 88, звонок помечается как эталон для обучения.

## Роли в расшифровке

Whisper отдаёт слова с таймкодами. Реплики собираются по паузам в аудио, затем классифицируются маркерами КЦ («меня зовут», «чем могу помочь», «хочу открыть» и т.д.). Соседние куски одной роли сливаются.

Это эвристика для двух спикеров, без облачной диаризации.

## Правка ASR

`app/asr_fix.py` поправляет устойчивые ошибки модели `base` на банковской лексике: «Центр-инвест», «ИНН», «ЕГРИП», «счёт».

На записи длиннее 90 секунд текстовая подсказка в Whisper не передаётся: иначе название банка может появиться в тексте само, и проверка скрипта станет ложноположительной. Короткие клипы подсказку получают.

## Локальная LLM (необязательно)

При `LLM_PROVIDER=ollama` к оценке правил добавляется мнение локальной модели (`app/llm.py`): четыре метрики смешиваются с весом `LLM_WEIGHT`, советы модели идут первыми с пометкой «ИИ:». Модель видит только замаскированный текст. Без Ollama или при ошибке используется только оценка правил. Настройка: [RUN.md](RUN.md#оценка-локальной-llm-ollama-необязательно).
