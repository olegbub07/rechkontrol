# Руководство пользователя

Интерфейс открывается по адресу [http://127.0.0.1:8080](http://127.0.0.1:8080). Данные обрабатываются на этой машине.

## Вход

На этой машине, пока пароли не сменены, экран входа показывает две учётки:

- администратор: `admin` / `CentrAdmin2026!` — все звонки, прослушивание любой записи, админка
- оператор: `operator` / `CentrOperator2026!` — только разговоры Ивановой (OP-104), без админки и без загрузки, экспорта и настроек

Смените пароли после первого входа. Кнопка **Пароль** есть в шапке. После смены плашка этой учётки на экране входа исчезает: если пароль администратора уже задан вручную, карточка показывает только оператора. Публичный пароль `CenterInvest2026!` из старой инструкции больше не открывает кабинет. Пока он ещё хранится в базе, программа один раз заменяет его на `CentrAdmin2026!`.

Аналитик по-прежнему смотрит все звонки, пишет заметки и скачивает KPI, но без админки. Удалять записи, менять скрипт и управлять людьми может администратор. Оператор чужой звонок не откроет.

## Разделы кабинета

| Раздел | Что здесь |
|---|---|
| **Обзор** | Среднее качество, четыре метрики, тренд, тональность, рейтинг операторов, очередь |
| **Звонки** | Журнал записей, фильтры, статусы очереди |
| **Загрузить** | WAV / MP3 / OGG в локальную очередь |
| **Операторы** | Сравнение сотрудников, добавление оператора |
| **Экспорт** | KPI в CSV и JSON |
| **Датасет** | MInDS-14: скачать, посчитать WER, импорт в очередь |
| **Скрипт** | Фразы компании и обязательные реплики |

Индикатор **очередь** в шапке показывает, сколько файлов ждут или обрабатываются, и открывает журнал. Пока есть живые задачи, журнал и досье обновляются сами. Бейдж **контур закрыт** в меню напоминает: аудио и текст не уходят во внешние сети. На узком экране разделы открываются кнопкой **Меню**.

## Первый просмотр без своих файлов

При первом запуске в журнал попадают демо-звонки. Программа на этой машине готовит для них русскую запись, и в досье появляется плеер. Администратор открывает и слушает любой звонок. Оператор слышит только свои. Пока файл ещё готовится, карточка пишет «Запись готовится на этой машине».

## Как загрузить запись

1. Откройте **Загрузить**.
2. Перетащите файлы или выберите их. Поддерживаются WAV, MP3, OGG, FLAC и M4A. Лишние по типу или размеру в список не попадают, любой файл можно убрать до отправки.
3. Укажите оператора и дату звонка, если известны.
4. Отметьте, говорит ли оператор первым (исходящий / стандарт КЦ).
5. Нажмите **Поставить в очередь**.

Статусы файла:

- **в очереди** — ждёт свободный слот;
- **обрабатывается** — расшифровка Whisper и оценка;
- **готово** — можно открыть досье;
- **ошибка** — файл не декодировался или запись слишком короткая.

Норматив кейса: 10 минут аудио за 3–5 минут на CPU. В досье готового звонка видно, уложилась ли обработка в этот бюджет. Жёсткий лимит длительности — 15 минут (`MAX_DURATION_SEC`). Подробности — в [PERFORMANCE.md](PERFORMANCE.md).

## Досье звонка

В карточке:

- плеер (для реальных файлов). Клик по реплике ставит воспроизведение на эту секунду, текущая реплика подсвечивается;
- поиск по репликам;
- копирование текста;
- пометка и заметка рецензента;
- краткое резюме;
- четыре метрики 0–100 и процент нарушений;
- рекомендации оператору;
- расшифровка по ролям «оператор / клиент»;
- чек-лист с доказательствами из текста.

Кнопка **Повторить обработку** снова ставит файл в очередь (нужен исходный аудиофайл). В журнале **Повторить ошибки** возвращает в очередь все сбойные файлы, у которых аудио ещё на диске. Демо-звонки без аудио повторно через Whisper не гоняются.

Поиск в журнале ищет и по имени файла, и по тексту расшифровки. Фильтр **только с пометкой** оставляет звонки, которые рецензент отметил.

На обзоре блок **Нужно внимание** собирает низкий итог (ниже 60) и высокий процент нарушений (от 40).

## Экспорт KPI

Фильтры: оператор и период. Форматы:

- **CSV** — русские заголовки, удобно открыть в Excel;
- **JSON** — те же поля;
- **JSON с расшифровками** — полный разбор.

Обязательные поля кейса: идентификатор оператора, дата и время, процент нарушений, среднее время ответа, тональность.

## Датасет

Раздел для проверки распознавания на открытом банковском наборе **PolyAI MInDS-14 (ru-RU)**.

1. **Скачать 24 клипа** — один раз, дальше офлайн.
2. **Проверить Whisper** — WER и CER относительно эталона.
3. **Импорт в очередь** — клипы идут тем же пайплайном, что и ваши звонки.

Файлы лежат в `data/datasets/minds14_ru/` и в git не попадают.

## Скрипт

В настройках задайте названия компании и дополнительные обязательные фразы (по строке). Они участвуют в метрике «соблюдение скрипта». Параметры модели Whisper меняются в `.env` и применяются после перезапуска.
