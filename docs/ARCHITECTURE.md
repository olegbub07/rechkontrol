# Архитектура

РечьКонтроль — локальное веб-приложение: FastAPI + SQLite + фоновый воркер + SPA без внешних CDN.

```
Браузер (SPA)
    │  JWT Bearer
    ▼
FastAPI  127.0.0.1:8080
    │
    ├─ SQLite (data/app.db)     метаданные, расшифровки, оценки
    ├─ Fernet                   аудио на диске (data/audio/*.bin)
    └─ Worker (потоки)          очередь queued → processing → done
            │
            ├─ ffmpeg           WAV/MP3/OGG → 16 кГц mono
            ├─ faster-whisper   русская речь → сегменты и слова
            ├─ diarize          реплики оператор / клиент
            └─ quality          4 метрики + рекомендации
```

## Поток обработки файла

1. Загрузка: проверка сигнатуры, лимита размера, шифрование, запись `Call` со статусом `queued`.
2. Воркер забирает следующий `queued` (FIFO), слотов не больше `MAX_PARALLEL_JOBS`.
3. Расшифровка во временный WAV, затем удаление plaintext из `data/tmp/`.
4. Whisper (`base`, `int8`, CPU): VAD отсекает тишину, луч 5. Запись короче 90 секунд идёт обычным проходом с короткой словарной подсказкой. Запись длиннее — пакетом (`BatchedInferencePipeline`), без подсказки в каждом окне, чтобы фраза банка не «протекала» в текст. Прогресс в базу пишется не чаще раза в 1,2 с. База не держится открытой на всё время расшифровки.
5. Нарезка реплик по паузам и маркерам КЦ, роли «оператор / клиент».
6. Оценка качества, сохранение транскрипта и KPI.
7. Статус `done` или `error` с понятным сообщением (без traceback в интерфейсе).

При аварийном останове задачи в `processing` при старте возвращаются в `queued`.

## Данные на диске (`data/`, gitignored)

```
data/
  app.db              SQLite
  master.key          ключ шифрования аудио
  jwt.secret          секрет JWT (отдельный файл)
  audio/              зашифрованные записи
  tmp/                временные WAV во время обработки
  models/faster-whisper-base/   локальная модель STT
  datasets/minds14_ru/          клипы и манифест датасета
```

## Модель данных

- **User** — вход в кабинет
- **Operator** — сотрудник КЦ, внешний ID
- **Call** — файл, статус, длительность, оператор, дата, пометка рецензента и заметка
- **Transcript** — полный текст и JSON сегментов
- **Quality** — четыре метрики, тональность, нарушения, рекомендации, чек-лист
- **Setting** — фразы скрипта

## Производительность

Норматив кейса — 10 минут аудио за 3–5 минут на CPU. Как этого добивается конвейер и чем можно пожертвовать, написано в [PERFORMANCE.md](PERFORMANCE.md).
