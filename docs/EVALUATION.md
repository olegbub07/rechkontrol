# Проверка оценки на 10 синтетических звонках

Звонки озвучены по сценариям с реальными продуктами банка Центр-инвест (вклады, ипотека, РКО, карты Mir Supreme и Пенсионная). Моно, 8 кГц, телефонная полоса, Silero TTS. Сценарии и ожидания лежат рядом с аудио в `scripts.md`.

Прогон: Whisper `small`, float32, CPU, без LLM (`LLM_PROVIDER=none`), чек-лист по умолчанию. Команда:

```
python scripts/eval_synth.py --audio ПАПКА_СО_ЗВОНКАМИ
```

Без аудио, на готовых репликах (они же в тесте `tests/test_synth_scoring.py`):

```
python scripts/eval_synth.py --json tests/fixtures/synth_calls.json
```

## Почему «Решение» было ровно 64,7

Группа «Решение» - это четыре критерия с весами: «Предложено решение» 1,3, «Следующие шаги» 1,1, «Подтверждение» 1,0, «Диалог не брошен» 1,2. В списках фраз были только слова про действие с заявкой: «оформил», «номер обращения», «карта заблокирована». На консультации оператор ничего не оформляет, а объясняет, что и где сделать. Поэтому в 01, 05, 08, 10 одинаково проваливались первые два критерия, а два других проходили:

(30 x 1,3 + 35 x 1,1 + 100 x 1,0 + 100 x 1,2) / 4,6 = 64,7

Что поменяли:

- «Предложено решение»: добавлены фразы консультации - «откройте раздел», «в приложении выберите», «можно открыть», «можно оформить», «можно заполнить», «откроется», «приходите в», «можно рассмотреть», «подойдёт», «рекомендую», «могу предложить», «зарегистрирую обращение».
- «Следующие шаги»: канал и документы - «в приложении», «в мобильном банке», «в офис», «с паспортом», «перезвонит», «придёт СМС», «зачисляется», «не позднее».
- «Диалог не брошен»: фразы отфутболивания - «всё на сайте», «там всё написано», «на сайте посмотри», «менеджер скажет», «это не ко мне», «ничем не могу помочь».
- Штраф за отфутболивание: если найдена такая фраза и при этом закрыто меньше 80% вопросов клиента, итог умножается на 0,8 (`BOUNCE_PENALTY` в `app/checklist.py`). Если оператор ответил по существу и только добавил «подробности на сайте», штрафа нет.
- Тональность: явная злость клиента («возмущён», «обман», «никто не говорил», «буду жаловаться» и т. п.) делает звонок негативным, даже если оператор вежлив. На саму оценку оператора это не влияет.

## Если чек-лист уже сохраняли в кабинете

Сохранённый чек-лист хранит свои списки фраз, и новые фразы из кода в него сами не попадут. Чтобы их получить, нажмите на странице чек-листа «Вернуть по умолчанию» (действие пишется в журнал) или добавьте фразы вручную. Уже оценённые звонки пересчитываются там же кнопкой пересчёта, без повторной расшифровки.

## Ограничения

- Это синтетика: чистая речь TTS, паузы между репликами, без шума и перебиваний. На живых звонках банка WER будет выше (см. `PERFORMANCE.md`, MInDS-14).
- Фразы подбирались с учётом этих 10 сценариев. Честная проверка - 5-10 обезличенных реальных записей с оценкой супервизора банка.
