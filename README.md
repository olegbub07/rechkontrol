# РечьКонтроль

Локальная платформа автоматической расшифровки звонков и оценки качества работы операторов. Прототип по технологическому кейсу ПАО КБ «Центр-инвест».

Аудио, расшифровки и оценки **не покидают машину**, на которой запущено приложение.

## Требования кейса

| Требование | Реализация |
|---|---|
| Speech-to-Text локально (Whisper) | `faster-whisper`, модель в `data/models/` |
| Вежливость, полнота, скрипт, решение + рекомендации | `app/quality.py` |
| Без передачи данных вовне | `127.0.0.1`, офлайн-модель, шифрование аудио, маскирование ПДн в выдаче (`app/pii.py`) |
| Запуск на ноутбуке / локальном сервере | `python run.py` или `.\run.ps1` |
| WAV, MP3, OGG | ffmpeg, проверка сигнатуры |
| Веб: загрузка, расшифровка, оценка, дашборд, экспорт | кабинет на `/` |
| KPI в CSV/JSON | нарушения, время ответа, тональность, дата, ID оператора |
| 10 минут записи ≤ 3–5 минут обработки | `base` + `float32`, VAD, пакетная расшифровка длинных файлов |
| Очередь | `queued → processing → done` |

## Быстрый старт

### Одной командой (Windows)

Двойной щелчок по `start.bat` или в PowerShell:

```powershell
.\start.bat            # Docker: приложение + PostgreSQL 17
.\start.bat -Llm       # то же + Ollama для оценки LLM (модель скачается один раз)
.\start.bat -NoDocker  # без Docker: .venv + SQLite
.\start.bat -Stop      # остановить (данные остаются)
```

Скрипт `start.ps1` проверяет, что Docker установлен и запущен (если Docker Desktop не запущен, запускает его), при первом запуске создаёт `.env` из `.env.example` со случайным паролем PostgreSQL, выполняет `docker compose up -d --build`, ждёт `/api/health`, печатает стартовые логины и пароли и открывает браузер. Если Docker нет или он не отвечает, скрипт сам переходит на запуск без Docker: создаёт `.venv`, ставит зависимости и запускает `run.py` в отдельном окне. Другие ключи: `-Port 8081` (порт на 127.0.0.1, по умолчанию `APP_PORT` из `.env`), `-NoBrowser`. Если стартовые пароли уже сменены, скрипт так и скажет; в Docker их можно посмотреть командой `docker compose exec app cat data/initial_credentials.txt`.

### Вручную

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
python run.py
```

Откройте [http://127.0.0.1:8080](http://127.0.0.1:8080)

Паролей по умолчанию нет. При первом запуске программа создаёт две учётки со случайными паролями:

- `admin` - администратор: все звонки, плеер и админка;
- `operator` - демо-оператор: только свои разговоры, без админки.

Пароли печатаются один раз в консоль и сохраняются в `data/initial_credentials.txt` (права 0600). При первом входе кабинет требует сменить пароль, до смены остальные разделы закрыты. После смены строка из файла удаляется. Свой пароль администратора можно задать заранее через `ADMIN_PASSWORD` в `.env`, смену при первом входе это не отменяет.

Если порт 8080 уже занят: откройте тот же адрес или выполните `python run.py --replace`.

При первом запуске в дашборд попадают **демо-звонки** (текст и оценка, без аудио). Озвучка демо-звонков необязательна и по умолчанию выключена: см. [docs/RUN.md](docs/RUN.md#озвучка-демо-звонков). Свои файлы — вкладка «Загрузить» у администратора.

Модель Whisper (`WHISPER_MODEL`, по умолчанию `small`, ~480 МБ, заметно грамотнее `base` при той же скорости в пакетном режиме) берётся из `data/models/faster-whisper-<модель>/`. Если папки нет, она скачается один раз, дальше контур офлайн.

## Оценка качества

Четыре метрики 0–100: вежливость, полнота ответа, соблюдение скрипта, решение проблемы. Итог — взвешенная сумма. Процент нарушений — доля непройденных пунктов чек-листа. Подробности — в [docs/QUALITY.md](docs/QUALITY.md).

Чек-лист (критерии, веса, ключевые фразы) администратор настраивает во вкладке «Скрипт», он хранится в БД. В карточке звонка подсвечены фрагменты, на которые сработали правила. На обзоре есть сравнение операторов, во вкладке «Экспорт» - PDF-отчёт по оператору за период (шрифт DejaVu лежит в `app/assets/fonts`, лицензия рядом).

## PostgreSQL

По умолчанию SQLite (`data/app.db`). PostgreSQL включается переменной `DATABASE_URL`, готовый `docker-compose.yml` с PostgreSQL 17 описан в [docs/RUN.md](docs/RUN.md#postgresql-вместо-sqlite-необязательно).
