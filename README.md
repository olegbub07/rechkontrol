# РечьКонтроль

Локальная платформа автоматической расшифровки звонков и оценки качества работы операторов. Прототип по технологическому кейсу ПАО КБ «Центр-инвест».

Аудио, расшифровки и оценки **не покидают машину**, на которой запущено приложение.

## Требования кейса

| Требование | Реализация |
|---|---|
| Speech-to-Text локально (Whisper) | `faster-whisper`, модель в `data/models/` |
| Вежливость, полнота, скрипт, решение + рекомендации | `app/quality.py` |
| Без передачи данных вовне | `127.0.0.1`, офлайн-модель, шифрование аудио, маскирование ПДн в выдаче (`app/pii.py`) |
| Запуск на ноутбуке / локальном сервере | `python run.py` или `.\run.ps1` |
| WAV, MP3, OGG | ffmpeg, проверка сигнатуры |
| Веб: загрузка, расшифровка, оценка, дашборд, экспорт | кабинет на `/` |
| KPI в CSV/JSON | нарушения, время ответа, тональность, дата, ID оператора |
| 10 минут записи ≤ 3–5 минут обработки | `base` + `int8`, VAD, пакетная расшифровка длинных файлов |
| Очередь | `queued → processing → done` |

## Быстрый старт

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
python run.py
```

Откройте [http://127.0.0.1:8080](http://127.0.0.1:8080)

Паролей по умолчанию нет. При первом запуске программа создаёт две учётки со случайными паролями:

- `admin` - администратор: все звонки, плеер и админка;
- `operator` - демо-оператор: только свои разговоры, без админки.

Пароли печатаются один раз в консоль и сохраняются в `data/initial_credentials.txt` (права 0600). При первом входе кабинет требует сменить пароль, до смены остальные разделы закрыты. После смены строка из файла удаляется. Свой пароль администратора можно задать заранее через `ADMIN_PASSWORD` в `.env`, смену при первом входе это не отменяет.

Если порт 8080 уже занят: откройте тот же адрес или выполните `python run.py --replace`.

При первом запуске в дашборд попадают **демо-звонки**. Запись для прослушивания готовится на этой машине. Свои файлы — вкладка «Загрузить» у администратора.

Модель Whisper (`WHISPER_MODEL`, по умолчанию `base`, ~145 МБ) берётся из `data/models/faster-whisper-<модель>/`. Если папки нет, она скачается один раз, дальше контур офлайн.

## Оценка качества

Четыре метрики 0–100: вежливость, полнота ответа, соблюдение скрипта, решение проблемы. Итог — взвешенная сумма. Процент нарушений — доля непройденных пунктов чек-листа. Подробности — в [docs/QUALITY.md](docs/QUALITY.md).
