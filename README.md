# РечьКонтроль

Локальная платформа автоматической расшифровки звонков и оценки качества работы операторов. Прототип по технологическому кейсу ПАО КБ «Центр-инвест».

Аудио, расшифровки и оценки **не покидают машину**, на которой запущено приложение.

## Что умеет прототип

| Требование кейса | Реализация |
|---|---|
| Speech-to-Text локально (Whisper) | `faster-whisper`, модель скачивается в `data/models/` |
| Оценка качества: вежливость, полнота, скрипт, решение + рекомендации | Движок `app/quality.py`, чек-лист и советы оператору |
| Без передачи данных во внешние сети | Bind `127.0.0.1`, Whisper офлайн при локальной модели, аудио на диске шифруется, JWT отдельно от ключа шифрования |
| Запуск на ноутбуке / локальном сервере | `python run.py` или `.\run.ps1` |
| WAV, MP3, OGG | ffmpeg из `imageio-ffmpeg`, проверка сигнатуры файла |
| Веб-интерфейс: загрузка, расшифровка, оценка, дашборд, экспорт | SPA на `/` |
| KPI в CSV/JSON | нарушения, время ответа, тональность, дата/время, ID оператора |
| 10 минут записи ≤ 3–5 минут обработки | модель `base` + `int8` на CPU, `beam_size=1`, VAD |
| Очередь | статус `queued → processing → done`, `MAX_PARALLEL_JOBS` |

## Быстрый старт

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
python run.py
```

Откройте [http://127.0.0.1:8080](http://127.0.0.1:8080)

- логин: `admin`
- пароль: `CenterInvest2026!`

При первом запуске в дашборд попадают **демо-звонки** (без аудио) — сразу видны метрики, тренды и карточки с расшифровкой. Реальные файлы загружаются во вкладке «Загрузить»: они встают в очередь, расшифровываются Whisper и оцениваются тем же движком.

Первый запуск Speech-to-Text берёт модель из `data/models/faster-whisper-base/` (~145 МБ). Если папки нет, Whisper скачает её сам. После этого контур работает офлайн.

## Как устроена оценка

Четыре метрики 0–100:

1. **Вежливость** — приветствие, «вы», формулы вежливости, эмпатия, отсутствие грубости и перебиваний.
2. **Полнота** — ответы на вопросы клиента, содержательность реплик, время реакции.
3. **Скрипт** — представление, название компании, предложение помощи, уточнение, закрытие. Фразы настраиваются в интерфейсе.
4. **Решение проблемы** — конкретное действие, следующий шаг, подтверждение, диалог не брошен.

Итог — взвешенная сумма. **Процент нарушений** — доля непройденных пунктов чек-листа. Рекомендации собираются только по проваленным проверкам.

Роли «оператор / клиент» размечаются по паузам и речевым маркерам КЦ (без облачной диаризации).

## Структура

```
app/
  quality.py      движок оценки
  transcribe.py   Whisper
  worker.py       очередь
  api/            REST
  static/         интерфейс
data/             БД, ключ шифрования, модели, аудио (gitignored)
```

## Настройки `.env`

- `WHISPER_MODEL` — `tiny` (быстрее), `base` (баланс), `small` (точнее)
- `MAX_PARALLEL_JOBS` — сколько записей обрабатываются одновременно, остальные ждут
- `MAX_UPLOAD_MB` — лимит файла

## Тесты

```powershell
.\.venv\Scripts\pytest
```

Тесты гоняют движок качества на эталонных диалогах и не требуют модель Whisper.
